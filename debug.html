6. Scheduled-event log

Scheduler errors describe the coarse JavaScript wake-up only; positive values are late. Beat targets use the audio clock and are queued ahead of playback. These values do not measure physical output latency.

Target audio time (s) targetTime / nextEventAudioTime firstEventAudioTime + eventGridIndex × eventIntervalSeconds Exact audio-clock beat target. Scheduled at (s) scheduledAt / audioTime audioContext.currentTime at scheduler wake Audio-clock time when the event entered the queue. Target interval (ms) eventIntervalSeconds (60 / bpm) × 1000 Intended spacing between beat targets. Phase error (ms) phaseErrorMs (nextEventAudioTime - idealTarget) × 1000 Deviation of the scheduled target from its anchored beat grid.
